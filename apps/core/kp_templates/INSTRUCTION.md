# Як зібрати й завантажити пакет КП (комерційної пропозиції)

> Чернетка, 2026-10-29. Імпорту в адмінці ще немає (його робить CMS). Місця, де ще не знаємо точних кроків, позначено **TODO**.

## 1. Що таке пакет
Пакет — це один zip-архів з усім вмістом сторінки КП: тексти, ціни пакетів, умови оплати й фото херо. Його завантажують в адмінку (Unfold), і сторінка `/proposal/<slug>/` з'являється без нового деплою сайту.

У пакеті змінюється **лише вміст сторінки КП**. Демо-сайт (демо-магазин, демо-лендінг, демо-корпоративний) — **стандартний для всіх КП**: ті самі фото, тексти, код і дизайн. Під клієнта його не змінюємо.

## 2. Що всередині архіву
```
мій-пакет.zip
├── manifest.json   — паспорт пакета (тип, версія, назва, дата)
├── proposal.json   — увесь вміст сторінки КП
└── media/          — фото (необов'язково)
    └── hero.webp
```
Файли лежать у корені архіву, без вкладеної папки.

Готові порожні шаблони лежать поруч:
| Тип КП | Шаблон | Підказки |
|---|---|---|
| Лендінг | `template-landing.zip` | `template-landing.HINTS.md` |
| Інтернет-магазин | `template-shop.zip` | `template-shop.HINTS.md` |
| Корпоративний сайт | `template-corporate.zip` | `template-corporate.HINTS.md` |
| Корпоративний сайт з каталогом | `template-corporate-catalog.zip` | `template-corporate-catalog.HINTS.md` |

Підказки винесено в окремі файли `.HINTS.md`, бо правил імпорту ще немає і ми не знаємо, чи пропустить він зайві поля в JSON.

## 3. manifest.json
| Поле | Що писати | Приклад |
|---|---|---|
| `type` | `landing`, `shop`, `corporate` або `corporate_catalog` | `"shop"` |
| `version` | версія формату пакета, поки завжди `1` | `1` |
| `title` | коротка назва КП для себе | `"КП — магазин квітів"` |
| `created` | дата збирання пакета, РРРР-ММ-ДД | `"2026-10-29"` |

`type` має збігатися з `kind` / `corp_catalog` у proposal.json (див. п. 4).

## 4. proposal.json
Назви полів такі самі, як у моделях сайту. Мови: поле без суфікса — українська, `_ru` — російська. Є ще `_en` і `_cs`; їх можна не додавати, вони лишаться порожні.

### 4.1. Головні поля (для всіх типів)
| Поле | Обов'язкове | Що це |
|---|---|---|
| `slug` | так | адреса `/proposal/<slug>/`. Латиниця, цифри, дефіс, до 160 символів, унікальна. Робіть невгадуваною: `shop-kvity-r7l2` |
| `client_name` | так | клієнт або назва проєкту, до 200 символів |
| `title`, `title_ru` | `title` — так | заголовок сторінки, до 300 символів |
| `lead`, `lead_ru` | ні | підзаголовок під заголовком |
| `recommendations_lead`, `_ru` | ні | вступ до блоку рекомендацій |
| `issued_on` | так | дата пропозиції, РРРР-ММ-ДД |
| `intro_html`, `_ru` | ні | «Про компанію / стек», можна HTML: `<p>`, `<strong>`, `<ul><li>` |
| `guarantee_html`, `_ru` | ні, але заповнюємо завжди | блок гарантії (HTML), див. п. 5 |
| `cta_label`, `_ru` | ні | текст кнопки, за замовчуванням «Обговорити проєкт» / «Обсудить проект», до 120 символів |
| `kind` | так | `landing`, `shop` або `corporate` |
| `corp_catalog` | ні | `true` лише для корпоративного сайту з каталогом |
| `is_published` | ні | `false` — сторінку не видно; вмикайте після перевірки |
| `order` | ні | порядок у списку КП, число |
| `hero_image` | ні | ім'я файлу з `media/`, напр. `"media/hero.webp"` (**TODO**: як саме імпорт вказуватиме фото) |

### 4.2. Списки (блоки сторінки)
- **`highlights`** — короткі пункти-плашки («Django / HTMX», «PageSpeed 95+», «10–14 днів»): `order`, `title`, `title_ru`.
- **`arch_nodes`** — схема сайту. Перший рядок (найменший `order`) — корінь, наступні — колонки. Поля: `title`, `caption` (+`_ru`), `is_accent` (`true` — помаранчева колонка).
- **`modules`** — що входить у роботу: `number`, `order`, `title`, `description` (+`_ru`).
- **`packages`** — пакети з цінами: `name`, `scope` (що входить), `duration` (строк), `price`, `price_high` (якщо є діапазон «від–до», інакше `null`), `currency` (за замовчуванням `€`), `is_recommended`, `order`.
- **`specs`** — три види карток, розрізняються полем `kind`:
  - `spec` — ТЗ / деталі проєкту;
  - `recommendation` — рекомендації PrometeyLabs;
  - `payment` — умови оплати.
  Поля: `title`, `body` (+`_ru`), `order`.

### 4.3. Ціни
Ціни пишемо **окремо для кожного КП** в `packages` (і за потреби в `payment`). В інструкції конкретних сум немає, у шаблоні стоїть `0.00`. Для довідки: інтернет-магазин — від 800 €, дропшипінг — від 1 500 €. Ціну пишемо числом з крапкою: `"399.00"`, без знака валюти (валюта — в `currency`).

### 4.4. Відмінності типів
| Тип | `kind` | `corp_catalog` | Важливо |
|---|---|---|---|
| Лендінг | `landing` | `false` | **Адмінки в лендінгу немає** — не обіцяйте її в `modules`, `packages`, `arch_nodes` |
| Інтернет-магазин | `shop` | `false` | Магазин **має CMS** (адмінку). Демо-магазин стандартний для всіх |
| Корпоративний сайт | `corporate` | `false` | — |
| Корпоративний з каталогом | `corporate` | `true` | Каталог без оплат і кошика: кнопка «Купити» відкриває форму заявки |

## 5. Гарантія (обов'язково, однаково в усіх КП)
- UA: **пожиттєва гарантія на код + 1 рік безкоштовної підтримки**
- RU: **пожизненная гарантия на код + 1 год бесплатной поддержки**

Приклад `guarantee_html`:
```html
<p>Ми надаємо <strong>пожиттєву гарантію на код + 1 рік безкоштовної підтримки</strong>.</p>
```
Сторінку `/offer/` пакет не змінює.

## 6. Фото (media/)
- Формати: **webp, jpg, png** (сайт приймає ще gif, але ми його не використовуємо).
- Назви: латиниця, без пробілів, напр. `hero.webp`.
- Зараз у КП є лише одне фото — **херо** (своє для кожного КП). Сайт збереже його як `proposals/<slug>/hero.<розширення>`.
- Розміри в схемі не задані. **TODO**: погодити з дизайном (орієнтир — широке горизонтальне фото).

## 7. Як заповнити й завантажити
1. Скопіюйте шаблон потрібного типу й розпакуйте.
2. Заповніть `manifest.json`: `title`, `created`.
3. Заповніть `proposal.json` за підказками з `template-<тип>.HINTS.md`. Тексти — живою людською мовою, як для клієнта.
4. Перевірте, що `kind`/`corp_catalog` відповідають `type` у manifest.
5. Покладіть фото в `media/` і впишіть його назву в `hero_image`.
6. Перевірте JSON (п. 8) і запакуйте **вміст** папки (не саму папку) у zip.
7. В адмінці Unfold відкрийте **TODO: розділ імпорту КП** → «Завантажити пакет» → оберіть zip.
8. Відкрийте `/proposal/<slug>/` і перегляньте UA та RU.
9. Якщо все добре, увімкніть `is_published` (в адмінці або в пакеті).

## 8. Перевірка й типові помилки
- Перевірка JSON: `python3 -m json.tool proposal.json` — якщо є помилка, команда покаже рядок.
- Кома після останнього елемента списку → помилка JSON.
- Лапки «ялинки» або ’ замість `"` навколо ключів → помилка JSON (у тексті всередині лапок — можна).
- `slug` уже зайнятий іншим КП → **TODO**: що зробить імпорт (оновить чи відмовить).
- Ціна з комою (`399,00`) або зі знаком € → помилка.
- Дата не у форматі РРРР-ММ-ДД → помилка.
- Архів з вкладеною папкою (`pack/manifest.json`) → імпорт не знайде файли.
- Фото не того формату або не з тією назвою, що в `hero_image`.
