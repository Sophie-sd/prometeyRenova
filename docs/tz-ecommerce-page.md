# ТЗ: Сторінка «Інтернет-магазини» — `/internet-shop/`

## Технічні параметри

- Файл шаблону: `templates/pages/internet-shop.html`
- URL: `/internet-shop/`
- Призначення: посадкова сторінка для рекламної кампанії «Інтернет-магазини»
- **Підхід: Mobile-first** — основний трафік зі смартфонів, кожен блок проєктується спершу для mobile

### Кольорова система (уточнена)

| Токен | HEX | Використання |
|---|---|---|
| `--color-bg` | `#0D0D0D` | Основний фон сторінки |
| `--color-surface` | `#1A1A1A` | Фон карток та блоків |
| `--color-accent` | `#FF6B35` | Помаранчевий акцент: кнопки, виділення, іконки |
| `--color-accent-hover` | `#E85D2A` | Hover для помаранчевих елементів |
| `--color-text-primary` | `#FFFFFF` | Основний текст |
| `--color-text-secondary` | `#A0A0A0` | Другорядний текст |
| `--color-border` | `#2A2A2A` | Роздільники та рамки |

### CTA-кнопки (єдиний стиль для всієї сторінки)

- **Основна кнопка:** помаранчевий фон `#FF6B35`, білий текст, border-radius відповідно до стилю сайту
- **Вторинна кнопка:** прозорий фон, помаранчева рамка `1px solid #FF6B35`, помаранчевий текст
- На сторінці використовуються 2 дії:
  - `Безкоштовна консультація →` → відкриває модальне вікно з номером / формою
  - `Заповнити бриф →` → плавний scroll (`#brief`) до форми в кінці сторінки
