# Kontur+ Design System Skill

Універсальний Cursor Skill для реплікації дизайну **Kontur+ Landing v2** у будь-якому проєкті.

## Вміст

| Файл | Призначення |
|------|-------------|
| `SKILL.md` | Інструкції агента (підключи в Cursor Skills) |
| `design-system-guide.md` | Повний Design System & UI Blueprint |
| `snippets.md` | HTML + CSS copy-paste |
| `css/` | Канонічні `tokens`, `base`, `components-1/2`, `motion` |

## Як підключити в Cursor

1. Скопіюй папку в персональні skills:

```bash
cp -R ~/Desktop/kontur-plus-design-system ~/.cursor/skills/kontur-plus-design-system
```

2. Або згадай Skill у чаті: «використай kontur-plus-design-system».

3. Агент має прочитати `SKILL.md`, далі гайд і `css/` за потреби.

## Джерело

Аудит `~/Sites/Kontur+/static/css/*` · Landing v2 · lime / cream / pill.
